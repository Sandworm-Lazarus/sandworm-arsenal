# Attribution and reuse

Sandworm Arsenal is an independent catalog. The authors and maintainers listed in [SOURCES.md](../SOURCES.md) created the linked projects. Listing a source does not imply affiliation, endorsement, or ownership of its skills.

## What belongs to this repository

The original summaries, editorial selections, starter packs, playbooks, artwork, and catalog scripts are released under this repository's [MIT License](../LICENSE). That license does not relicense any external project. No upstream skill bundle is included.

## Before adapting an external skill

Read the license and notices at the exact revision you plan to use, including per-directory licenses. Preserve required credit and notices, identify your changes, and keep the applicable license with redistributed material. The source register is a research note; the actual license text controls reuse.

Selected cases from the reviewed snapshot:

| Source | Reuse note |
| --- | --- |
| Trail of Bits | CC BY-SA 4.0; account for attribution and ShareAlike when sharing adaptations |
| OWASP Secure Agent Playbook | CC BY 4.0 and third-party notices |
| Anthropic skills | Apache 2.0 was read in six inspected folders; this is a scoped finding, not a blanket assumption about every file |
| Impeccable | Apache 2.0 plus notices; inspect the included NOTICE |
| NVIDIA skills | README and selected RAG entry frontmatter describe licensing at different scopes; resolve scope before redistribution |
| haikow/claude-reverse-skills | No root LICENSE was found in the reviewed tree; a partial MIT declaration does not resolve the whole bundle |
| Datacraft Cybersecurity Skills | A community fork, not an official Anthropic project; retain upstream provenance |

For a portfolio adaptation, explain the specific improvement: a new fixture, a useful workflow, better evaluation, Thai documentation, or platform support. Keep that contribution distinct from the original author's work.
